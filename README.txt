Description:
This application tracks real-time stock prices using the Yahoo Finance API and sends email alerts to users using Mailjet. It can track multiple stocks, send emails when prices change, and repeat updates every 5 minutes.

Technologies Used:
- Python
- yfinance (for stock data)
- Mailjet (for sending emails)
- plyer (for desktop notifications)
- schedule (for timing)

Instructions to Run:
1. Install required packages using: pip install -r requirements.txt
2. Run the file using: python stock_tracker.py
3. Enter stock symbols and email when prompted.

Note: Mailjet API keys must be set up in the code for sending email alerts.
